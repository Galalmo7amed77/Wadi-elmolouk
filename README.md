# Wadi El Molouk for Spinning & Weaving – Website

Static bilingual (Arabic / English) website. No build step.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (public).
2. Upload the contents of this folder to the repository root (index.html, images/, robots.txt, .nojekyll).
3. Settings > Pages > Build and deployment: Source = "Deploy from a branch", Branch = main, folder = / (root).
4. Wait a minute, then open the Pages URL shown in Settings.

## Before going live
- Add absolute URLs for og:image and a sitemap.xml once the final domain is known.
- Replace the privacy policy placeholder section with the full policy.
- WhatsApp number is set in the script (WA_NUMBER). Contact details are in the footer.
